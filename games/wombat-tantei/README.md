# ウォンバット☆さがしものたんてい（試作中）

ひらがなを覚えはじめた未就学児向けの推理ゲーム。逆転裁判の「しらべる → たいけつ（いいわけのうそにカードをつきつける）」の流れを、裁判ぬきで借りています。

## 守りたいこと

- **読み上げに頼らない。** 会話は絵とドット絵のふきだしで伝え、画面に出るひらがなは「答えになることば」だけにする
- 最初は大人がついて遊び、**すぐに子ども1人で遊べる**ようにする
  - 操作は 👆 のアニメーションとアイコンで伝える。しばらく操作がないと自動でヒント
  - 大人向けの「おはなし」の文は設定で消せる
- 間違えても何も失わない（ゲームオーバーなし）。相棒のモモをタップするとヒント
- カードの見せ方で読む力を少しずつ求める：1話は絵つき、2話はかげ絵＋最初の文字に色、3話は文字だけ（しらべてカードを手に入れるときは毎回絵と文字を見せる）
- 犯人はこわくしない。最後は仲直りして終わる

## キャラクター

- 主人公：ウォンバット。シリーズ共通の描画コード（`games/kami-wombat`・`tokei-wombat` と同じ `renderFront` / `renderWombat`）をそのまま使う。待っているときは正面顔、歩くときは横向き
- 相棒：フクロモモンガの「モモ」。オレンジのスカーフで、高いところへ飛んで調べる。明るく元気な空の相棒という役どころだけを参考にした、オリジナルのキャラクター

## ドット絵

- ウォンバットは index.html の中の共通描画コードで、起動時に描く
- モモ・カード・いいわけの絵は `src/sprites.py`（`assets/animal-sprites/src/raster.py` の描画部品を使用）
- ほかの動物は `assets/animal-sprites` のもの
- 描き直したら `python3 src/build.py` で `index.html` の `/*PX*/` 〜 `/*/PX*/` を書き換える

## 音

効果音もBGMも Web Audio で合成している（音声ファイルなし）。BGMは「⚙ おとな」で切れる

## 保存

`localStorage` の `wtantei_save`（クリアしたおはなし、途中の状態、設定）
