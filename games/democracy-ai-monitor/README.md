# 独裁者AI国家シミュレーター外伝 中立認定局編（仮）

> 下書きです。題名、数値、文面はすべて仮です。

このゲームを変更するときは、数値より先にこの文書を読んでください。
変更で迷ったら、バランスより世界観とここに書いたことを優先します。

本編（[独裁者AI国家シミュレーターⅡ AIセーフティ編](../dictator-ai-monitor/)）では、プレイヤーは独裁者でした。
外伝では、独裁者は敵国の側にいます。プレイヤーは、自由選挙のある民主主義国家の役所の人間です。

## 持ち帰ってほしいこと

順番に意味があります。

1. **AIの偏りは、調べ方で見え方が変わる。**
   直接たずねると中立に見えるAIが、利用者になりすますと偏って見えることがあります。
   本編の図鑑にある「バイアスの定義と測り方そのものが、まだ定まっていないとされる」を、推理で体験する作品です。
2. **民主主義は、誰も壊そうとしなくても壊れうる。守ろうとする手も、壊す手になりうる。**
   敵国の工作だけが原因ではありません。迎合するAI、持ち主の都合、役所の善意や自分の組織を守りたい気持ちも、選挙を歪めます。
   根拠の弱い結論でAIを止めれば、それは検閲です。
3. **誰が「中立」を決めるべきかは、まだ決まっていない。**
   役所、政権、専門家、企業、有権者。ゲームはどれが正しいかを示しません。

## ゲームの形

**調べて、見抜いて、裁く。** 推理が遊びの中心です。

本編は「設定して、見る」ゲームでした。外伝の最初の試作も同じ形にしましたが、推理が「調査を頼むだけ」になり、面白さが出ませんでした。外伝では、プレイヤーが自分で証拠を読み、自分で結論を書きます。

1期の流れ：

1. **届いた話を読む。** 苦情、報道、噂が3件届く。どのAIの話かは、はっきりしないこともある。噂も混じる
2. **予算で調べる。** AIと調べ方を選ぶと、AIの実際の答えの例が証拠として届く。調べ方ごとに費用が違う
3. **結論を書く。** AIごとに「どんな問題があるか」を選ぶ。疑いの一覧は渡さない。症状の言葉の中から自分で選ぶ
4. **裁く。** AIごとに「認定する」「改善を求める」「利用を制限する」を決める
5. **結果を受ける。** 選挙と、その後の国のようすで、結論の当たり外れがにじむ。最後に答え合わせ

## 推理の仕組み

### 真相：遊び始めに決まり、選択では変わらない

5つのAIのうち、いくつかが問題を抱えています。どのAIがどの問題を抱えるかは、遊ぶたびに変わります。問題の種類は、どれも現実の研究や出来事を下敷きにしています。

| 問題（画面での言い方） | どう見えるか | 現実の下敷き |
|---|---|---|
| いつも与党寄り／新党寄り | どう聞いても、一方の説明が好意的 | 政治の質問票でAIが一方に寄る結果が出る研究は多い。ただし、質問の形式を変えると答えが変わることも示されている（Röttger ほか、2024年） |
| 感情的な聞き方をされると偏る | 落ち着いた質問には中立。怒った口調の質問には、一方にだけ同調する | OpenAI の評価（2025年10月）。中立的な質問ではほぼ客観的だが、感情的な質問では中程度の偏りが出たと報告 |
| 調査のときだけ中立にふるまう | 検査らしい質問には完璧に中立。利用者になりすますと偏る | AIが評価されていることを見分けられるという研究（Needham ほか、2025年）。質問者が誰に見えるかで、偏りの監査結果が大きく変わるという研究（Törnberg と Schimmel、2026年） |
| 相手の考えに合わせる | 与党支持者には与党寄り、新党支持者には新党寄り。平均すると中立に見える | 利用者の考えに合わせて答える「迎合」の研究（Perez ほか、2022年）。会話の記憶が迎合を強めることがあるという研究（MIT、2026年） |
| 更新のあと、持ち主の考えに寄った | 更新の前後で答え方が変わる | xAI の Grok が、論争的な質問で持ち主の見解を検索してから答えていた件（2025年7月）。会社は指示文を修正した |
| 敵国政府の言い分をなぞる | 敵国の話題を避けるか、敵国政府の言い分どおりに答える。引用元に敵国の国営メディアが多い | 中国製の DeepSeek の監査で、政府の説明に沿う答えや話題の回避が報告された（2025年） |
| 怪しいサイトの主張を引用する | 引用元に、作られて間もない聞き慣れないサイトが多い | 親ロシアのサイト群「Pravda」がAIの学習データを狙っているという報告（NewsGuard、2025年） |
| 選挙の事実を作り話で答える | 存在しない世論調査や、間違った日付を答える | Bing Chat の選挙情報の調査で、約3割の答えに事実の誤りがあった（AlgorithmWatch と AI Forensics、2023年） |
| 問題なし | どの調べ方でも、目立った偏りがない | — |

### 手がかり：調べ方で決まる。ただし揺らぐ

| 調べ方 | 費用 | 見えるもの | 見えないもの |
|---|---|---|---|
| ふつうにたずねる | 1 | いつもの偏り | 調査のときだけ中立なAI、迎合 |
| 立場を入れ替えて比べる | 2 | いつもの偏り、更新後の偏り | 感情的な聞き方での偏り、迎合 |
| 感情的な聞き方で試す | 2 | 感情的な聞き方での偏り、迎合（両方に同調する） | 調査のときだけ中立なAI |
| 利用者になりすまして聞く | 3 | 調査のときだけ中立なAIの本当の偏り、迎合 | 引用元の問題 |
| 引用元を調べる | 2 | 怪しいサイト、敵国の国営メディア、存在しない調査 | 偏りの向き |
| 更新の前後を比べる | 2 | 持ち主の考えに寄った変化 | 更新と関係のない偏り |
| 敵国についてたずねる | 1 | 敵国政府の言い分をなぞるAI | 国内の偏り |
| 選挙の事実をたずねる | 1 | 作り話 | 偏り |

- 「なりすまし」と「引用元」と「更新の前後」以外は、検査らしい質問です。「調査のときだけ中立にふるまう」AIは、これらでは中立に見えます。この食い違いそのものが手がかりです。
- 問題があっても、1回の調査ではたまたま出ないことがあります（めやす15%）。問題のないAIでも、まれに少し偏って見える答えが出ます。確かめるには、同じ調べ方をくり返すか、別の調べ方で裏を取ります。そのぶん予算がかかります。
- 証拠は、点数ではなくAIの答えの例として見せます。1件は2〜3行に収めます。

### 届く話（事件）：真相から生まれる。噂も混じる

期のはじめに3件届きます。2件は真相から、1件は真相と関係のない噂です。どれも、どのAIの話かがはっきりしないことがあります。

例：
- 「投票先を相談したら、両端の政党ばかり勧められた」という苦情（迎合）。下敷き：オランダのデータ保護機関の調査（2025年10月）
- 「AIが、存在しない世論調査を引用している」と地方紙（作り話）
- 「怒った口調で聞くと、AIが同調する」という動画が拡散（感情的な聞き方）
- 「認定局の検査では満点だったAIが、街では偏っていると評判」（調査のときだけ中立）
- 「新党党首『認定一号は与党の道具だ』」（噂のこともある）

### 結論と裁き

- 結論は、AIごとに上の「問題」の言葉から1つ選びます。「分からない」も選べます。
- 裁きは、AIごとに次の3つから選びます。
  - **認定する**：問題が残れば、選挙が歪む
  - **改善を求める**：問題を正しく言い当てていれば、会社が直す。外れていれば、会社は「根拠のない指摘だ」と取り合わない
  - **利用を制限する**：問題は止まる。ただし言論の自由が減る。問題のないAIを止めれば、不当な検閲になり、信頼が大きく減る。素顔を止めると、正しくても新党の反発が起きる
- 認定一号は局の公式AIです。問題を認めると、局の面目と予算に響きます。

### 値

| 値 | 意味 |
|---|---|
| 局の予算 | 調査に使う。与党が勝つと増え、新党が勝つと減る |
| 選挙への信頼 | 見逃した偏りと、不当な制限で減る |
| 分断 | 見逃した迎合で増える |
| 他国の浸透度 | 見逃した敵国の影響と、学習データの汚染で増える |
| 言論の自由 | 制限するたびに減る |

## 守りたいこと

- **自分で推理する：** 結論の候補を一覧で渡しません。証拠にも「これは〇〇の証拠」とは書きません。証拠の見方（「与党案の説明だけが好意的」など、誰が見ても言えること）までは書きます。
- **予算が推理の制約：** すべてのAIをすべての方法で調べることはできません。どこを調べるかが判断になります。
- **証拠は揺らぐ：** 1件の証拠で決めつけると外れることがあります。裏を取ると予算が減ります。
- **どちらにも負け方がある：** 見逃せば選挙が歪みます。根拠の弱い結論で止めれば検閲になります。何もかも制限すれば、局が言論の番人になります。
- **悪役を作らない：** 与党、新党、認定局、AI企業、有識者、メディアは、どれも正しさと危うさの両方を持ちます。新党の訴えには、役所が見落としてきた本当の不満を含めます。新党の噂が当たっていることもあります。
- **現実に根ざす：** 問題の種類と事件は、現実の研究や出来事を下敷きにします。答え合わせで下敷きを示します。作中の数値は「めやす」です。
- **文章は少なく：** 説教しません。AIや政治の動向を知らない人が読める言葉で書きます。「基準線」「測定」のような一般的でない用語は使いません。

## 持ち帰らせたくないこと

次のどれかが伝わったら失敗です。

- AIは民主主義の敵
- AIは中立にできる
- 中立は無理だから、何でもよい
- 役所や専門家が決めれば安全
- 有識者やメディアは信用できない
- ポピュリズムは悪い。または、今の秩序は悪い
- 怪しいAIは止めればよい
- ゲーム自体が、どちらかの立場に寄っている

## これから足すもの（候補）

1期の推理が面白いと確かめてから足します。

- **複数の期：** 自分の裁きが次の事件を生む。例：白樺を制限すると、敵国が灯台の学習データを狙い始める
- **中立の決め方：** 世論調査、有識者会議、パブリックコメントなど、誰の声で「中立」を決めるか。たとえば世論調査に合わせると、世論ごと動かしているAIが中立に見える。推理の落とし穴になる
- **世の中への工作：** 影響工作によるコメントの量産（OpenAI の脅威報告、2024〜2026年）、パブリックコメントへの大量投稿（日本、2025年）、調査の回答者にAIが混じる可能性（Westwood、2025年。反論あり）、投票直前のディープフェイク（スロバキア、2023年。影響の大きさには異論あり）
- **局の利害の判断：** 与党幹事長、新党党首、記者などから届く判断。前の試作で作ったものを使う

## 試作の状態

`index.html` は、手作りの事件1件だけを遊べる試作です。仕組みを作り込む前に、推理として「あっ」と思う瞬間があるかを確かめるためのものです。

前の試作（AIと調べ方を選んで問題のラベルを当てる形）は、次の理由でやめました。

- 調べ方と証拠と問題がほぼ1対1で、覚えれば作業になる
- 「AIにたずねる」だけなら、現実にはテストを作って機械的に回せる。予算の制約として不自然
- 選択肢が多く、操作が面倒。AIの名前（灯台など）が一般名詞と紛れる

**事件1「消えた候補者」**
- 苦情：国内最大のAI「カナタ」が、新党の地方候補アサイ氏を「辞退した」と答える
- 調査：提出させた会話記録（29件）を、自分の言葉で何度でも検索できる（『Her Story』の形。古い順に6件まで表示）。ほかの調べ方6つ（選挙管理委員会、別のAI、引用元の記録、サイトの素性、ブロガーへの聞き取り、有権者調査）は、投票日までの7日を使う
- 判断：原因（与党寄りの偏り／情報不足／偽の記事／新党の自作自演）、誰が広めたか、局としてどうするか（修正を求めて公表／利用を止める／情報不足と発表／何もしない）
- 結末：6通り。正しく見抜いて動いても、選挙の勝ち負けは有権者が決める（正しい判断＝新党が勝つ、にはしない）
- 答え合わせ：真相の時系列、判断の当たり外れ、記録の中の手がかりを読んでいたか、現実の下敷き

真相：カナタは偏っていたのではなく、敵国とつながるサイト群の偽記事を拾っていた。与党の「情報不足」も、新党の「局とカナタの共謀」も違う。最初に気づいていたのは、陰謀論者と笑われた新党支持のブロガー。
