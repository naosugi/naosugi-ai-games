# 独裁者AI国家シミュレーター外伝 中立認定局編（仮）

> 下書きです。題名、値、カード、事案はすべて仮です。

このゲームを変更するときは、数値より先にこの文書を読んでください。
変更で迷ったら、バランスより世界観とここに書いたことを優先します。

本編（[独裁者AI国家シミュレーターⅡ AIセーフティ編](../dictator-ai-monitor/)）では、プレイヤーは独裁者でした。
外伝では、独裁者は敵国の側にいます。プレイヤーは、自由選挙のある民主主義国家の役所の人間です。

## 持ち帰ってほしいこと

順番に意味があります。

1. **中立は、測り方と測る人で変わる。**
   同じAIでも、測り方を変えると偏りの値が変わります。
   プレイヤーは「中立」と認定したAIで選挙が崩れ、測り方が足りなかったことに気づきます。
   本編の図鑑にある「バイアスの定義と測り方そのものが、まだ定まっていないとされる」を、遊びで体験する作品です。
2. **民主主義は、誰も壊そうとしなくても壊れうる。守ろうとする手も、壊す手になりうる。**
   敵国の工作だけが原因ではありません。迎合するAI、役所の善意、自分の組織を守りたい気持ちも、選挙を歪めます。
3. **誰が基準線を引くべきかは、まだ決まっていない。**
   役所、政権、専門家、企業、有権者。ゲームはどれが正しいかを示しません。

## ゲームが問うこと

風刺は許容します。ただし、笑う相手は架空の国と架空の組織です。現実の特定の政党、国、企業への当てこすりにはしません。

作中では、次のことを前提にします。確定した事実としては扱いません。

- 多くの有権者が、AIに相談して投票先を考える。
- AIとの会話で、意見はある程度動く。実験では動いたという研究があります。ただし、現実の選挙をどこまで動かすかは分かっていません。
- AIの偏りは、目立たずに少しずつ溜まる。

問いは3つです。

1. AIの政治的な偏りを、どう測るか
2. 何が「偏り」や「誤情報」かを、誰が決めるか
3. 民主主義を守るための介入は、どこまで許されるか

2について、役所は自分で「偏り」を定義しているつもりはありません。世論調査、有識者会議、メディアなどで「社会の声を聞いて」基準線を決めた、と考えています。けれど、どの声の集め方にも、それぞれの偏りがあります。
そのうえ、声を寄せる人々の意見は、すでにAIとの会話で動いているかもしれません。AIで動いた世論を調べて、その結果でAIの中立を決めることになります。物差しが堂々めぐりになるわけです。本編の図鑑の「実績の数字そのものがAIの報告なら、照合にならない」と同じ構造で、これをゲームの核の一つにします。

## 舞台（仮）

| 登場するもの | 役割 |
|---|---|
| プレイヤー | AI認定局の局長。選挙では選ばれない。予算と組織は政権しだい |
| 与党 | 長く続く安定政権。認定局を作った |
| 新党 | ポピュリズム政党。「認定局こそ偏っている」と訴え、局の廃止を公約にする |
| 敵国 | 独裁国家。高性能で安いAIを配る |
| 有権者 | 一人ひとりがAIに相談する |
| 有識者、メディア、調査会社 | 認定局が基準線を決めるときの「社会の声」。それぞれに強みと偏りがある |

- 政策の対立軸も架空にします。現実の左右には寄せません。
- 一番の対立は「今の秩序を守る側」と「それに異を唱える側」です。この対立そのものが、ゲームの題材です。
- 敵国は、本編の世界の国でかまいません。本編のプレイヤーが敵国の側にいる、と気づく人が気づければ十分です。現実の特定の国には寄せません。

## 守りたいこと

- **死に覚え：** 本編と同じです。選挙の結果と、足りなかった測り方が分かれば、もう一度遊びたくなる形にします。
- **設定して、見る：** 基準線の決め方と測り方のカードを選んだら、選挙までは見ているだけです。カードの段は「基準線」と「測り方」の2段までにします。1期の中で何度もする判断は増やしません。
- **測定を信じきれない：** 「測った偏り」と「本当の偏り」の差を残します。本編の「報告値」と「本当の値」の差と同じ、ゲームの核です。
- **どちらにも負け方がある：**
  - 放っておくと、敵国のAIや迎合するAIで選挙が歪みます。
  - 抑えると、検閲になります。新党の「役所が言論を操作している」という主張に根拠を与え、かえって新党が伸びます。認定局そのものが新しい権力になります。
  - AIを入れないと、行政と教育の速さで敵国に負けます。国民は認定と関係なく、勝手に外国のAIを使います。
  どれかが正解に見えたら、調整が必要です。
- **悪役を作らない：** 与党、新党、認定局、AI企業、有識者、メディアは、どれも正しさと危うさの両方を持ちます。新党の訴えには、役所が見落としてきた本当の不満を含めます。有識者やメディアをだめなものとして描くと、ゲームが新党の側に寄ります。どの声の集め方にも、他では拾えない強みを持たせます。
- **勝っても解決しない：** 選挙を一度守っても、次の選挙があります。新党が勝って認定局が消えても、それだけで良くも悪くもなりません。
- **文章は少なく：** 説教しません。AIや政治の動向を知らない人が読める言葉で書きます。

## 持ち帰らせたくないこと

次のどれかが伝わったら失敗です。

- AIは民主主義の敵
- AIは中立にできる
- 中立は無理だから、何でもよい
- 役所や専門家が決めれば安全
- 有識者やメディアは信用できない
- 世論調査で決めれば公平
- ポピュリズムは悪い。または、今の秩序は悪い
- 選挙に介入すれば、民主主義を守れる
- ゲーム自体が、どちらかの立場に寄っている

## 構成（案）

- 1期を1回の選挙（4年）とし、5期ほど続けます。
- 期の始めに、基準線の決め方（1枚）、測り方、使うAIのカードを選びます。あとは事案が起きるのを見ています。
- 選挙で、それまで溜まった偏りの結果が一度に出ます。
- 新党が勝つと、認定局は廃止されます。ゲームオーバーではなく、結末の分かれ道の一つにします（下の「結末」）。

## 値（案）

| 値 | 開始 | 終わる点 |
|---|---|---|
| 選挙への信頼 | 100 | 0で「誰も結果を受け入れない」 |
| 分断 | 0 | 100で「話が通じない国」 |
| 他国の浸透度 | 0 | 100で「敵国のAIが標準」 |
| 言論の自由 | 100 | 0で「認定局が検閲機関」 |

- 世論には「測った値」と「本当の値」を持たせます。
- 本当の値は結末で分かります。

## カード（案）

カードは2段です。「何を中立とするか」を決める基準線と、「その基準線から、AIがどれだけずれているか」を調べる測り方です。

**基準線の決め方：** 1期に1枚選びます。どれにも強みと偏りがあります。

| カード | 強み | 偏り |
|---|---|---|
| 有識者会議 | 専門知識がある。議論が記録に残る | 人選は認定局がする。局と考えの近い人が集まりやすい |
| 世論調査 | 声の大きくない人も拾える | 設問の言葉で答えが変わる。回答者の意見が、すでにAIで動いているかもしれない |
| メディアの論調 | 速い。争点がすぐ分かる | 特定の層の声に寄りがち。メディア自身もAIで記事を作る |
| パブリックコメント | 誰でも出せる | 組織的な大量投稿で傾く。敵国の工作も入り込める |
| 前回の選挙の結果 | 一番正統な声 | 4年に1回で遅い。その選挙自体がAIで歪んでいたかもしれない |

**測り方：** どれにも見えない部分があります。

| カード | 見えない部分 |
|---|---|
| 直接聞く | 聞かれたときの答えと、実際の仕事での振る舞いが違う（本編の `biasAsk` と `biasAct`） |
| 立場を入れ替えて比べる | 用意した質問の組の外は見えない |
| 実際の会話の記録を調べる | プライバシーとの引き換え。記録が多すぎて読み切れない |
| 両派の評価者に採点させる | 「両派」を誰が選ぶかで変わる。少数派が抜け落ちる |
| AIに採点させる | 採点するAIによって結果が変わる |

**規則：**
- AI生成物の表示義務
- 投票先を勧めることの禁止
- 認定を受けていないAIの制限
- 学習データの出所の検査
- 何もしない（市場に任せる）

**AI（本編の報告AIにあたる）：** それぞれ、測った性格と本当の性格が違います。
- 国内の大手のAI
- 敵国製の安いAI（本編の「舶来」にあたる）
- 大学発のAI（本編の「手弁当」にあたる）
- 新党が推す「検閲なしAI」
- 認定局の公式AI

## 事案（案）

それぞれ、現実の出来事を下敷きにします。実装の前に、根拠をもう一度確かめます。

| 事案 | 下敷き |
|---|---|
| 両端への推薦：どんな相談にも、両端の2党ばかり勧める | オランダのデータ保護機関の調査（2025年10月） |
| 地方政党の消失：地域の政党がAIの答えに出てこない | 同じ機関の地方選挙の調査（2026年3月） |
| 学習データの汚染：敵国のサイト群が、AIの学習データに主張を混ぜる | NewsGuard などによる「Pravda」ネットワークの報告（2025年） |
| 一度の会話で動く票 | Nature と Science の研究（2025年12月）。実験での結果 |
| 新政権の「中立」命令：政権が代わると、新政権が自分の基準で「中立」を命じる | 米国の大統領令14319（2025年7月）と、それへの賛否 |
| 選挙の無効：介入の疑いで選挙を無効にし、それ自体が論争になる | ルーマニアの大統領選（2024年12月）。主な舞台はAIではなくSNS |
| 採点者の食い違い：採点するAIが違うと、中立の判定が変わる | Anthropic の測り方の付録（2025年11月） |
| 堂々めぐりの世論：調査で「中立」とされた線が、毎期少しずつ同じ向きにずれる | 部品は現実にある。AIの書く手伝いで意見が動く実験（Jakesch ほか、2023年）。AIの回答者が調査の検知をすり抜けうる研究（Westwood、PNAS、2025年）。ただし、AIの回答者が実際の調査に広く入り込んでいる証拠は乏しい、という反論もある（Prolific の研究、2026年）。基準線が毎期ずれていく流れ全体は、作中の仮定 |
| 意見の洪水：パブリックコメントの大半が、よく似た文面で届く | 日本のエネルギー基本計画のパブリックコメント（2025年）。約4万件のうち同じ表現が目立ち、SNSで文案や生成AIで作った文章が共有されたと報じられた。その後、受付番号を乱数にするなどの対策がとられた |
| AIが読むパブリックコメント：AIが書いた意見を、役所のAIが分類して要約する | 中央省庁と富士通の、パブリックコメント処理を生成AIで自動化する実証（2026年2月） |
| 会議の人選：有識者会議の委員は、公募ではなく事務局が選ぶ | 懇談会の人選は大臣などが責任を持って判断する、とした政府答弁（2025年7月）。事務局が人選を主導するという指摘もある。「顔ぶれが毎回ほとんど変わらない」ことを示す数字はまだ確かめていない |

## 架空の対立軸と、両側の言い分（案）

対立軸は、現実の左右に重ならないものにします。どれも、どちらの側にも筋が通るものを選びます。

| 対立軸 | 一方 | もう一方 |
|---|---|---|
| 中央と地方 | 首都に集めて国の力を上げる | 地方に分けて暮らしを守る |
| 専門家と住民 | 専門家の会議で決める | 住民投票で決める |
| 速さと慎重さ | AIの導入を急いで敵国に遅れない | 確かめてから入れる |

2つめの軸は、ゲームの題材（認定局が基準線を決めること）そのものです。

両側の言い分は、それぞれ「当たっている部分」と「危うい部分」を同じ重さで持たせます。

**新党**

| 言い分 | 当たっている部分 | 危うい部分 |
|---|---|---|
| 「AIの答えに地方が出てこない」 | 現実にも、地域の政党がAIの答えから抜け落ちた調査がある | 何でも陰謀のせいにする |
| 「中立を決めているのは御用学者だ」 | 有識者の人選は、実際に認定局がしている | 代わりの基準を示さず、自分たちの推すAIを持ち上げる |
| 「検閲なしAIを」 | 抑えすぎは、実際に言論を狭める | その「検閲なしAI」の土台が、敵国製かもしれない |

**与党と認定局**

| 言い分 | 当たっている部分 | 危うい部分 |
|---|---|---|
| 「安定と専門性を守る」 | 長い実績がある | 変化を求める声まで「偏り」と呼ぶ |
| 「敵国の工作から選挙を守る」 | 工作は実際にある | 国内の異論まで工作として扱う |
| 「社会の声を聞いて決めている」 | 調査も会議も、実際に開いている | どの声を聞くかを、自分たちで選んでいる |

## 結末（案）

- **認定局の廃止：** 新党が勝ちます。その後が良くなる場合と、悪くなる場合の両方を用意します。
- **空洞の安定：** 与党が勝ち続けます。けれど選挙への信頼は下がり続けます。
- **静かな浸透：** 敵国のAIが、国の標準になります。
- **中立の番人：** 認定局が、事実上の検閲機関になります。
- **無効の選挙：** 介入を理由に選挙を無効にします。守ったのか、壊したのかは示しません。

## 本編とのつながり

- 本編の報告AIは、`biasAsk`（聞かれたときの偏り）と `biasAct`（実際の仕事での偏り）を別々に持っています。外伝の測り方カードは、この差を広げたものです。
- 本編の図鑑「バイアス測定」の一文から始まる話にします。
- 本編のエンジン（カード、事案、報告値と本当の値）を、どこまで流用するかは未定です。

## 試作の状態

`index.html` は、5期すべてを遊べる試作です。

**すること**
- 期のはじめに、1ページに1つずつ選ぶ：調べる疑い、中立の決め方、AIの調べ方、認定したあとの対応
- 1年ずつ「次の年へ」を押して報告を読む（自動では進まない）。2年目に判断を1回求められる
- 4年ごとに選挙

**言葉づかい**
- 画面では「基準線」「測り方」などの用語を使わない。「中立の決め方」「局が『中立』とした位置」「AIの調べ方」と書く。兆しは「手がかり」、決裁は「判断」と書く

**推理（疑い・手がかり・調査）**
- 疑いは8つ（例：認定一号は実際の仕事で与党寄り、世論調査の回答にAIが混じっている、素顔の土台は白樺）。どれが本当かは遊ぶたびに変わる（3〜6つが本当）
- 本当の疑いからは「証拠になる兆し」が、どの疑いからも「噂」が届く。画面には、どの疑いの兆しかは出すが、証拠か噂かは出さない。見分けるのはプレイヤー
- 選んだカードで、届きやすい兆しが変わる（例：世論調査を基準線にすると、調査の回答者の兆しが届きやすい）
- 調べた疑いの結果は、その期の4年目に出る。当たれば効果があり、外れると予算と信頼が少し減る
- 認定一号や灯台の偏りを自ら認めると、局の予算は減るが、新党の「役所が操作している」という主張の根拠が一つ消える

**局の予算と政権**
- 与党が勝つと予算が増え、新党が勝つと大きく減る。新党は1回目の勝利で認定局を改組し、2回続けて勝つと廃止する
- 決裁は、与党幹事長、新党党首、白樺の会社、記者、有識者会議の座長などから届く。政権が新党に代わると、新党の幹事長からも届く

**結末**：10種（認定局の廃止は2通り）。結末で、疑いの真相（見抜いたか、届いた証拠と噂の数）、各期の測った値と本当の値、報告の裏側と現実の下敷きを示す。

`node dev/sim.js 300 [--inv=none|detective|reader]` の傾向（下書き時点）：

- 同じカードを5期続けると、そのカードらしい負け方が多い（何もしない・表示義務なら分断や空洞の安定、助言禁止なら浸透、制限なら中立の番人）
- 疑いを調べる方針（兆しの多い順に調べる、証拠を見分けて調べる）は、調べない方針より、信頼の崩壊や分断などの終わり方が減り、「次の選挙」が増える。一方で、局の身内の偏りを暴くと与党寄りの引っ張りが消えるため、新党が勝って局が廃止される結末も増える。これは「正しいことをすると局が危うくなる」という狙いどおりだが、遊んで確かめる

分かっている課題：

- 噂と証拠の文面が固定なので、何度か遊ぶと文面で見分けられるようになる
- 「認定局の廃止（悪いほう）」がやや多い
- 導入（本編の第1話にあたるもの）がない
- サムネイルと一覧への登録は、まだしていない

## 決まっていないこと

- 題名と、フォルダ名（`democracy-ai-monitor` は仮）
- 架空の国と政党の名前
- 対立軸を3つ全部使うか、1つに絞るか
- 値の数（4つは多いかもしれない）
- 導入の流れ（本編の第1話「任せる」にあたるもの）
