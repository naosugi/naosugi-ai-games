# シミュレーター

ウォンバット☆レガシーRPG 2 の数字（経験値・敵の強さ・職業の差）を決めるための道具。画面はまだない。

## ファイル

- `core.js` … ゲームの処理（職業・転職・引き継ぎ枠・スキル・敵・戦闘・おまかせ）。DOMを使わない。画面を作るときは、前作と同じく中身を `index.html` に入れる
- `sim.js` … おまかせで自動プレイさせて、数字を集める。結果は `report.md` に書き出す
- `test.js` … 決めたルール（解放条件は1匹ずつ、6枠、倒れた仲間に経験値なし など）が守られているかのテスト
- `report.md` … 最後に実行した結果

## 使い方

Node.js 18 以上が必要。

```
cd games/wombat-legacy-rpg-2/sim
node sim.js                    # ぜんぶ実行して report.md を書き出す（30秒くらい）
node sim.js check              # 目標との比較だけ（調整するときに使う）
node sim.js matrix             # 階×レベルの勝率表だけ
node sim.js campaign --hours 40 --seeds 5
node --test test.js
```

## 調整する場所

- 敵の強さ：`core.js` の `CONFIG.enemyCurve`（B1・10・20・30・40・50の値を決め、あいだはなめらかにつなぐ）。敵の種類ごとの倍率と技は `ARCH`、出てくる組み合わせは `floorGroups`
- 状態異常の確率、バフの効果など：`core.js` の `CONFIG`
- 職業の倍率・必要経験値の係数：`core.js` の `JOBS`（上級職・超上級職の倍率は、今は条件の職業から自動で作っている仮の値）
- スキル：`core.js` の `SKILLS`
- 遊ぶ時間のめやす（1戦・1階あたりの秒数）：`sim.js` の `TIME`
- 自動プレイの進め方（町に戻る条件、転職の順番、引き継ぎ枠の選び方）：`sim.js`

## 自動プレイの仮ルール

- 戦闘はすべて「おまかせ」
- HPが4割を切る、回復役のMPが少ない、仲間が倒れたら町に戻る
- 戦闘のあいだ（HPが55%未満）とボスの前に、手持ちの薬草・まほうのしずくを使う
- B5で「掘る」が使えるようになったら、近道を掘って1階あたりの戦闘が1回へる
- 順番待ちの仲間は、極めた職業でいちばん強いものに戻る（レベル上限のまま）
- 全滅が2回続いたら、1つ浅い中継地点から始める。2回続けて無事に戻れたら、1つ深い中継地点から始める
- 転職したてで育成中（上限の半分未満）の仲間は、同時に1匹まで
- 目標の超上級職は 1匹目=万能王、2匹目=魔道王、3匹目=忍者王。極めたら、B50のボスを倒すまではそのまま
- 装備は職業に合う系統（ツメ・つえ・ふえ）で、町に戻るたびに買えるいちばん強いものを買う
