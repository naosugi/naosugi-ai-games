# ウォンバット☆レガシーRPG 2（制作中）

[ウォンバット☆レガシーRPG](../wombat-legacy-rpg/) の続編。前作を遊んだ人向けの、やりこみ型のコマンドRPG。

- 前作の3匹の子どもたちが、ユーカリ村にあいた地下50階の穴にもぐる
- 町は1つ。行ったことのある階ならどこからでも始められる
- 転職するとLv1から。わざは「引き継ぎ枠」に6つまで持っていける
- 「やわらかい壁」は掘れる。番人つきの光る宝箱もある

いまは段階②（B1〜20、基本職6種、転職・引き継ぎ枠・掘る）まで遊べる。

## 守りたいこと（前作から）

- 負けても何も失わない（戦闘の前からやり直すか、村に戻って全回復）
- 迷ったら「おまかせ」で戦える
- スマホの縦画面で遊べる
- 現実の動物の説明は事実に合わせる。空想のところは図鑑にそう書く

## ファイル

- `index.html` … 公開するゲーム（`build.py` が作る。直接編集しない）
- `build.py` … `sim/core.js` と `src/` を1つの index.html にまとめる
- `src/` … 画面（`ui.js`）、ドット絵と音楽（`render.js`）、データ（`game.js`）、ひな形（`template.html`）
- `sim/` … ゲームのルール（`core.js`）とシミュレーター。ルールはゲームとシミュレーターで共通
- `DESIGN.md` `SKILLS.md` `STAGE2.md` … 設計メモ

```
python3 games/wombat-legacy-rpg-2/build.py   # index.html を作り直す
cd games/wombat-legacy-rpg-2/sim && node --test test.js
```
