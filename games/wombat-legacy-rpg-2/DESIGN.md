# ウォンバット☆レガシーRPG 2（仮）設計メモ

[ウォンバット☆レガシーRPG](../wombat-legacy-rpg/) の続編。B50と結末、クリア後の隠しボスまで作った。このメモは決めたことと、まだ決めていないことの整理。中身の詳細は [STAGE2.md](STAGE2.md)（B1〜20）と [STAGE3.md](STAGE3.md)（B21〜50・結末）。

- **決定**：持ち主と相談して決めたこと
- **案**：おすすめとして出したもの。シミュレーションや試遊で変えてよい
- **未定**：これから決めること

## 1. ねらい

- **決定** 前作を遊んだ人向けの、やりこみ型の続編。遊ぶ時間が長くなってよい
- **決定** 前作の「守りたいこと」は続ける。特に次の4つ
  - 負けても何も失わない（全滅したら、戦闘の前からやり直すか、町に戻って全回復）
  - 迷ったら「おまかせ」で戦闘の指示を自動で出せる
  - 誤操作を防ぐため、対象を確認する画面をはさむ
  - 状態が目に見える。スマホの縦画面で、スクロールせずに1画面に収まる
- **決定** 単調にならないよう、メリハリを意識してつける
  - 特徴のある敵
  - やけに強い装備やスキル
  - 職業ごとのはっきりした差

## 2. 物語（テーマ：受けつぐ）

- **決定** 主人公は前作の3匹の子どもたち（次の世代）
- **案** 前作の3匹（せんし・まほうつかい・そうりょ）は町にいる師匠役。転職のときに技を受けつぐ場面で出てくる
- **案** 結末はB50の奥。前作の長老の言葉「レガシーとは 宝では ない。〜 その くらしこそが、わしらの のこしたものじゃ」を、次の世代の目線で受け取り直す
- **案** 前作のセーブ（`wombatlegacy_save_v1`）が残っていれば、親の名前や最終レベルが会話に出てくる（おまけ。前作のデータは読むだけで、書きかえない）

## 3. 全体の構成

- **決定** 町は1つ
- **決定** ダンジョンは1つで、地下50階まである。前作と同じ迷路型（種から生成し、行き止まりは宝箱）
- **決定** 浅い階に戻って遊べる
- **決定** パーティは前作と同じ3匹

### 階の並べ方（案）

| 階 | エリア | おもな出来事 |
|---|---|---|
| B1〜10 | 巣穴の層 | 前作に近い感覚で慣れる。B5で「掘る」を解放。B10の大ボスを倒すと転職を解放 |
| B11〜20 | ユーカリの根の層 | 基本職を育てる。毒使いや歌い手が活きる敵を多めに置く |
| B21〜30 | 地下水脈の層 | 下へ掘る縦穴（近道づくり）を解放。最初の上級職が解放されるのはこのあたり |
| B31〜40 | オパールの層 | お金やレア装備が手に入りやすいが、強い敵が多い |
| B41〜50 | 太古の層 | 化石・古代の生き物。超上級職が解放され始めるのはこのあたり。B50が最終ボス |

- **決定** 10階ごとに、ダンジョンの色合い・BGM・出てくる敵を大きく切りかえて、メリハリを出す（2026-11-22）。中身は [STAGE3.md](STAGE3.md)
- **決定** 町からは、行ったことのある階ならどこからでも始められる（いちばん深い階も含む）。ボス前の緊張感は減るが、50階を毎回歩き直す負担をなくすほうを取る
- **案** 5階ごとに中ボス。倒さないと先へ進めない
- **決定** ボスの階の入り口に回復ポイントは置かない
- **案** 10階ごとに大ボス。エリアの区切り
- **決定** ボスは強め（人間は自動プレイより上手なため）。めやすは、その段階の上限レベル・満タンで勝率6〜8割
- **決定** 前作と同じく、番人に守られた光る宝箱を置く（エリアに1体、B8・18・28・38・48）。何度でも使える回復の道具は出さない
- **案** クリア後に、超上級職向けの隠しボスを置く（作った：ドロップベア。[STAGE3.md](STAGE3.md) の8c）
- 解放が起きる階はめやす。シミュレーションで調整する（例：転職を解放するときに、基本職のレベル上限20に届いているか）

### 現実の内容を使うとき

- 前作と同じく、敵はオーストラリアの動物をもとにし、図鑑の説明は資料で確かめてから書く。空想の生き物は図鑑にそう書く
- オパールの層：オーストラリアには地下でオパールを掘る町がある、という話をもとにする（書く前に確かめる）
- 太古の層：ウォンバットの遠い親戚にあたる絶滅した大型有袋類（ディプロトドンなど）を「先祖」として出す案。どの動物をどう説明するかは、資料で確かめてから決める

### 装備

- **決定** 職業ごとには作らない。武器は3系統
- **決定** ツメ（こうげき）・つえ（まりょく＋こうげき少し）・ふえ（こうげきとまりょくの両方）の3系統。どの職業でも装備できる。防具は1系統
- **案** 強さの割り振り：つえはこうげき25%、ふえは両方に70%ずつ

## 4. 町とクエスト

- **決定** クエストを達成すると、店に並ぶ品が強くなる
- **案** クエストはエリアごとに3つ。前作と同じく、どれか1つを達成すると店の品ぞろえが1段上がる。残りの2つはやりこみ用のごほうび（光る宝箱級の装備など）
- **案** クエストの種類
  - 前作からのもの：ボス討伐、宝探し、お金集め
  - 新しいもの：掘って埋まった物を見つける、状態異常で特定の敵を倒す、など職業の個性が活きるもの

## 5. 掘るアクション

- **決定** 途中で解放する（案ではB5）
- **決定** 掘れるのは「やわらかい壁」だけ。ただし、掘れる場所は多めにして自由度を高くする
- **案** ボス部屋のまわりは硬い壁にする（ボスを避けて進めないように）
- **案** 掘った見返りを置く：埋まった宝、隠し部屋、近道
- **案** 下へ掘る縦穴を、地下水脈の層で解放する
- **案** 掘った結果は階ごとに保存する。壁1マスを1ビットで持てば、50階分でも小さく済む見込み

## 6. 職業と転職

### 基本ルール（決定）

- 転職するとレベル1に戻る（初めての職業のとき）。ステータスは引き継がない
- **前にきたえた職業に戻ったときは、前回のレベル・経験値から続ける**（決定。極めた職業はレベル上限のまま）
- 職業によってステータスが割合で変わる（職業ごとの倍率）。ただし、ぼうぎょは倍率の対象にしない。かたさの差はHPの倍率でつける
- **レベルが上がると HP と MP が全回復する**（決定。前作と同じ。テンポのため。倒れている仲間は経験値をもらえないので、生き返らない）
- 職業ごとに、レベルアップに必要な経験値の表を変える。強いスキルを持つ職業ほど重く、それ以外は軽くする（同じ基本職の中でもばらつきをつける）
  - **案** 基本職：僧侶1.3・魔法使い1.2・空手家1.1・戦士0.6・毒使い0.6・歌い手0.6（数字が大きいほど重い）。上級職・超上級職にも同じ考え方を入れる（未定）
- レベル上限：基本職20、上級職30、超上級職40
- レベル上限に届くと、その職業の強いスキルが手に入る
- 引き継ぎ枠：パッシブスキルととくぎを**合わせて6個**まで。今の職業のとくぎ・パッシブは、これとは別にレベルアップで増えていく
- 引き継ぎ枠は町でいつでも付け替えられる
- 極めた職業に戻ったときは、レベル上限のまま
- パッシブスキルには、ステータスを上げるものもある（強くなりすぎないかは、あとで数字を調整する）
- 戦闘中に倒れている仲間には経験値が入らない
- 上級職・超上級職の解放条件は1匹ずつ数える（ほかの仲間が極めた職業は数えない）
- **案** 職業一覧で、1匹ごとの解放の進み具合が見えるようにする
- 深い階ほど経験値が多い。レベルの低い仲間を守りながら進むのも楽しみの一つ
- **経験者ボーナス**（決定 2026-11-22）：上級職を1つでも極めた仲間は、基本職の経験値が3倍。2回目以降の基本職育成を短くするため
- **すごいハリモグラ**（決定 2026-11-22）：B21〜 オパールハリモグラ、B31〜 おうごんハリモグラ。「アリづかの かけら」で出やすくなる（STAGE3.md 8f）
- **深い層の経験値の上乗せ**（決定 2026-11-22）：B31〜40は1.5倍、B41〜50は2倍（コアラ討伐の報酬にも同じ倍率）

### 基本職（6種・決定）

| 職業 | 得意なこと |
|---|---|
| 戦士 | 前作どおり。かたくて、仲間をかばって攻撃を受け止める |
| 空手家 | 戦いながら自分を強くする。守りは低めで、カウンター（反撃）がある |
| 魔法使い | 攻撃魔法 |
| 僧侶 | 回復（前作の「まもりの葉」は、バフ役の歌い手にゆずる） |
| 毒使い | 状態異常とデバフ |
| 歌い手 | バフ |

#### 空手家のしくみ

- **決定** 戦士は前作どおりの守り役。空手家は自分バフとカウンターが得意
- **案** 自分バフは「きあい」という別の種類にして、歌い手のバフと同時にかかるようにする（前作のバフは重ねがけできないので、上書きし合わないように）
- **案** 攻撃するとついでに「きあい」が1段たまる（最大3段、大技を出すと消える）。雑魚戦でもむだなターンが出ず、ボス戦ではためて大技を出せる
- **案** カウンターは、攻撃をよけたときや受けたときに確率で発動する。攻撃を集めるしくみは持たせない（戦士の守り役とかぶらないように）
- 引き継ぎ枠でカウンターを戦士系に持っていくと「かばって反撃」ができる。やけに強い組み合わせの候補だが、強すぎないかはシミュレーションで見る

### 上級職（9種）

- **決定** 基本職を2つレベル上限にすると解放される。どの基本職も、ちょうど3つの上級職に関わる（6×3÷2＝9）
- 6つから2つを選ぶ組み合わせは15通りあるので、そのうち6通りには上級職がない

組み合わせと名前は**決定**（方向性は案）。

| 上級職 | 組み合わせ | 方向性（案） |
|---|---|---|
| 上級戦士 | 戦士＋空手家 | 正統派。かばう守りと反撃を合わせ持つ |
| 狂戦士 | 戦士＋毒使い | 自分に毒や状態異常をかけ、そのかわり攻撃力が大きく上がる |
| 聖騎士 | 戦士＋僧侶 | かばう・守り・回復 |
| 魔拳士 | 空手家＋魔法使い | 属性つきの物理攻撃 |
| 舞闘家 | 空手家＋歌い手 | 踊りながら戦う。「きあい」と歌のバフをつなぐ |
| 幻術師 | 魔法使い＋歌い手 | 敵の行動をみだす、味方の魔法を強める |
| 呪術師 | 魔法使い＋毒使い | 強いデバフと魔法 |
| 聖歌士 | 僧侶＋歌い手 | 回復とバフをまとめてかける |
| 薬師 | 僧侶＋毒使い | 状態異常をかけるのも治すのも得意 |

この並べ方なら、どの基本職もちょうど3回ずつ出てくる。上級職がない組み合わせは、戦士＋魔法使い、戦士＋歌い手、空手家＋僧侶、空手家＋毒使い、魔法使い＋僧侶、毒使い＋歌い手の6通り。

### 超上級職（6種）

- **決定** 決まった組み合わせの上級職を4つレベル上限にすると解放される
- **決定** 組み合わせのヒントは、いろいろな形で出す
- **案** 職業一覧に「？」のシルエットを並べ、条件を少しずつ明かす（あいまいすぎて行き詰まらないように）
- **決定** 名前は「〇〇王」でそろえる
- **案** 条件と方向性

| 超上級職 | 条件（上級職4つ） | 方向性（案） |
|---|---|---|
| 忍者王 | 舞闘家・魔拳士・幻術師・薬師 | すばやさ・回避・状態異常・忍術 |
| 万能王 | 上級戦士・聖騎士・魔拳士・聖歌士 | 守り・回復・属性攻撃をそこそこ全部。何でもできすぎないよう、ピンチで強くなるなどの個性をつける |
| 魔道王 | 幻術師・呪術師・聖歌士・薬師 | 強い攻撃魔法と強い回復の両方 |
| 突撃王 | 上級戦士・狂戦士・魔拳士・呪術師 | とにかく大きなダメージを出す |
| アイドル王 | 舞闘家・幻術師・聖歌士・聖騎士 | 歌い手系の上級職3つが前提。パーティ全体を強くする |
| あなほり王 | 上級戦士・狂戦士・舞闘家・薬師 | ウォンバットらしさの職業。掘ると確率でアイテムが手に入り、低い確率で最強装備の素材が出る |

- 上級職ごとの使われる回数：上級戦士・魔拳士・舞闘家・幻術師・聖歌士・薬師が3回、狂戦士・聖騎士・呪術師が2回（計24）
- どの2つの超上級職も、共通する条件は2つまで（条件が似すぎないように）
- **案** ヒントの出し方：転職所の表示、ボス・番人から手に入る「いにしえの 石ばん」、長老での読み返し（[STAGE3.md](STAGE3.md) の5）

#### あなほり王の素材（決定）

- 掘った壁は残す。ただし各階にいくつかある「あやしい壁」だけは、町に戻るとまた埋まり、何度でも掘れる
- 深い階ほど良い物が出る
- 素材を町に持ち帰ると、その素材に関係する装備が店に並ぶようになる（鍛冶屋などの新しい施設は作らない）

## 7. 戦闘

- **決定** 雑魚戦は約2ターンでよい。そのかわり、敵ごとに特徴のある攻撃をさせる
- **決定** 転職した直後は、楽に勝てないようにする
- **決定** 魔法系・デバフ系の敵を増やす。敵の魔法とブレスは、ぼうぎょに関係なくダメージを与える
- **決定** コアラは強敵。強力な魔法を使い、職業別のコアラ（まほうつかい・そうりょ・うたいて・どくつかい・せんし・からてか）もいる。中身は [STAGE2.md](STAGE2.md)
- **案** 特徴のある敵（実在の動物の当てはめは STAGE2.md）：パーティをねむらせる／まひさせる／歌のバフときあいを消す・MPを吸う／自爆する／仲間を回復する／いちばんHPが少ない仲間を狙う／物理攻撃に反撃する／魔法をはね返す／力をためて大技（予告つき）／物理攻撃をよく避ける。深い階ほど種類が増える
- **案** ボスは深いエリアほど技が増える（ねむり、バフ消し、ため、ねらいうち）
- **決定** B41〜50は、敵も経験値もほかの区間より急に強くする（今の値はB40→50でHP約2.8倍・攻撃力約1.8倍・経験値約3倍）
- **案** B50の大ボスは、敵の強さの表から計算せず個別に決める。表どおりだと、超上級職Lv40・最強装備でも勝率1%ほどになるため
- **決定** スキルの配分は [SKILLS.md](SKILLS.md)。基本職は6つずつ。全体に効く強いバフ・無属性魔法・自動で起きる効果は上の段階で覚える
- **決定** ふっかつのいのり（僧侶の上限）は、仲間を1匹えらぶとくぎ。自動で起きるパッシブは超上級職（魔道王）
- **決定** 物理ダメージは前作と同じ「こうげき − ぼうぎょ÷2」（足りないときは1〜2）。1ダメージだらけにならないよう、敵の攻撃力の伸び、敵の状態異常・デバフで釣り合いをとる。シミュレーターで「1ダメージになった攻撃の割合」を見る
- **決定** 前作の毒に「ぼうぎょが下がる」効果を足す（毎ターンのダメージに加えて）
- **決定** 状態異常は確率でかかる分、効果を強くする。強いくらいがちょうどよい
- **決定** ボスには、状態異常がかかる確率を下げる（まったく効かないわけではない）
- **案** 同じ状態異常をくり返しかけると、かかりにくくなるしくみも候補
- **案** かかる確率を画面に出す
- **案** 敵からかけられる側の対策も用意する（治すとくぎ、防ぐ装備＝おまもり。[STAGE3.md](STAGE3.md) の8c）
- **案** 低レベルの仲間ばかりが一撃で倒れて面倒にならないよう、敵の狙い方やレベルの低い仲間を守る装備で調整する

## 8. 作り方

- **決定** シミュレーションで数字を確かめながら、段階的に作る
- 前作のコードには、戦闘の処理を Node.js からも呼べるようにした部分がある（`typeof module`）。戦闘の処理を画面と切り離し、「おまかせ」で自動プレイして数字を集める
- シミュレーションで見る数字
  - 階ごとの勝率と、戦闘にかかるターン数
  - 1時間あたりのレベルの上がり方と、各職業を解放するまでにかかる時間
  - 転職した直後に、どの階まで戦えるか
  - 特定の職業・スキル・装備が強すぎないか（採用率が偏っていないか）

- シミュレーターは `sim/` にある。使い方は [sim/README.md](sim/README.md)、最新の結果は [sim/report.md](sim/report.md)

### 段階（案）

3. B21〜30、上級職、縦穴（作った）
4. B31〜50、超上級職、結末（作った）
5. クリア後の要素（隠しボス ドロップベアを作った）
