# ウォンバット☆レガシーRPG

ウォンバット3匹（せんし・まほうつかい・そうりょ）の、昔ながらのコマンド選択式RPG。

## ねらい

- **JRPGを遊んだことがない人でも最後まで遊べる**こと。全体で約60分
- 町は施設をボタンで選ぶだけ。歩くのはダンジョンの中だけにして、迷わないようにしている
- 町ごとにクエストが3つあり、どれか1つを達成すると次の町へ行ける（ボス討伐・宝探し・お金集め）

## 守りたいこと

- **負けても何も失わない**。全滅したら「戦闘の前からやり直す」か「町に戻って全回復」を選べる。宿屋はお金が足りなくても泊まれる
- **迷ったら「おまかせ」**。戦闘の指示を自動で出せる
- **誤操作を防ぐ**。敵が1体でも、全体攻撃でも、必ず対象を確認する画面をはさむ。仲間を選ぶときは、HPの見える仲間カードを押す
- **状態が目に見える**。弱点アイコン、敵のHPバー、仲間カードの「まもり↑3」「どく」など
- **メリハリ**。メタル枠のハリモグラ、仲間を呼ぶディンゴ、毒、2回行動、店の目玉装備、番人つきの光る宝箱（強い装備や何度も使える道具）
- スマホの縦画面で、ページがスクロールせずに1画面に収まる。ダンジョンでは画面と十字キーが同時に見える

## しくみ

- ウォンバットの絵は [神に愛されたヒメウォンバット](../kami-wombat/) の描画コード（`renderWombat` / `renderFront`）を流用し、職業ごとの帽子を重ねている
- ダンジョンは床・壁などのドット絵の組み合わせ。迷路は種（seed）から作るので毎回同じ形になる。行き止まりはすべて宝箱、いちばん奥が階段かボス
- BGMはオリジナル曲を Web Audio で鳴らしている（音声ファイルなし）
- 保存は `localStorage`。セーブデータは「セーブ1・2・3…」と複数持てる（`wombatlegacy_slot_<番号>`）。「はじめから」で次の番号が増え、「つづきから」で選ぶ・消すができる
- `wombatlegacy_save_v1` には、最後に保存したデータの写しを書き続けている。続編（[ウォンバット☆レガシーRPG 2](../wombat-legacy-rpg-2/)）が前作のレベルと名前を引き継ぐときにこのキーを読むため。複数セーブにする前のデータは、最初に開いたとき「セーブ1」に移す
- 音のオン・オフは `wombatlegacy_snd`

## 図鑑の豆知識

敵はオーストラリアの動物がもと。図鑑の説明は豪州博物館などの資料で確かめた内容に合わせている。空想の生き物（かげディンゴ、きんのハリモグラ、しおだまりのぬし、いにしえの番人）は図鑑にそう書いている。ドロップベアは旅行者をからかう作り話の動物として紹介している。
