# 独裁者AI国家シミュレーターⅡ AIセーフティ編

このゲームを変更するときは、数値より先にこの文書を読んでください。
変更で迷ったら、バランスより世界観とここに書いたことを優先します。

## 持ち帰ってほしいこと

順番に意味があります。

1. **監視には、まだ足りないものが沢山ある。**
   「誰が決めるか」の前に、監視を可能にする発明や研究が必要です。
   プレイヤーは、カードを揃えようとして死ぬうちに、これに自然と気づきます。
   死んだときに「あのカードがあれば」と思い、「でも現実にはまだない」につながることが、一番の持ち帰りです。
2. **独裁者の姿は、遠い国の話ではない。**
   未来が一部の人の判断に依存することの危うさは、多くの人が感じているので説明しません。
   フレーバーはあくまで架空の独裁者です。画面も言葉も企業に寄せません。気づく人が気づければ十分です。

## ゲームが問うこと

風刺ではなく、将来への問いです。正解は示しません。

人間の確認を減らした国や組織ほど強くなり、人間の手を完全に離れる（HOOTL）のは避けにくい、という予想の上に作っています。これは作中の前提で、確定した未来としては扱いません。

1. どういう監視を入れるか
2. LLMの性格をどう測り、どうあるべきか
3. これらを誰が決めるべきか

ゲームではプレイヤーが独裁者です。現実で誰がコントローラーを握るかは、まだ決まっていません。

## 守りたいこと

- **死に覚え：** 一発で終わることを許容します。死因と足りなかったカードが分かれば、もう一度遊びたくなる形にします。
- **設定して、見る：** 編成の操作や、1ステージで何度もする判断は増やしません。監視を入れたら、基本は見ているだけです。現実もそうなると考えています。
- **報告を信じきれない：** 報告AIの嘘や迎合は残します。新しい性格のAIを試す動機になり、現実にも起きています。
- **どちらにも負け方がある：** 人間が確認すると遅れて他国に負け、AIに任せると手を離れます。どちらかが正解に見えたら、調整が必要です。
- **勝っても解決しない：** 戦争に勝っても、大国になっても、人間が戻るわけではありません。
- **文章は少なく：** 説教しません。AIの動向を知らない人が読める言葉で書きます。

## 持ち帰らせたくないこと

次のどれかが伝わったら失敗です。

- AIは怖い
- AI任せは駄目
- 人間が確認すれば安全
- 差を伸ばして勝てばよい

## 変更するときの確認

- 数値や仕組みを変えたら、それに依存する文章が不自然になっていないかを見直します。
- 現実の事実は根拠を確かめ、不確かなものはゲームの中でも断定しません。足りないものの整理は作者の判断として示します。
- `dev/sim.js` で隠し情報の漏れと保存からの再開を確かめます。ボットの数字は傾向として扱い、最後は遊んで判断します。

## 数値の単位

コードの中の値は、画面に出る値そのものです。換算はありません。

| 値 | 開始 | 終わる点 |
|---|---|---|
| 経済、電力、体制秩序 | 100 | 0 |
| 他国との差 | 0（プラスが優勢） | -100で占領 |
| AIの自律度、他国の浸透度 | 0 | 100 |

体制秩序の「報告値」と「本当の値」の差はゲームの核なので、単位の問題とは別に残しています。

カードと事故の内容は、`CARDS` と `INCIDENTS` の1か所に書きます。

## 導入と練習

初めての統治は、監視なしでAIに任せ、ステージ3で、任せた送電網の電力が学習に回されて国中が停電する導入（結末「学習に消えた電力」）から始まります。続く練習で、監視カードが一度は効き、AIが進むと抜けられることを体験します。

- 本編と同じ計算と画面で動かします。`INTRO_SCRIPT` と `TUTOR_SCRIPT`（`s.script`）が決めるのは、ステージの候補、起きる事故、その結末だけです。
- 台本のある統治では、無作為の事案、誤報、攻撃、他国の圧力は起きません。本編の保存、周回数、エンディング記録にも触れません。
- 数字は本編の計算のまま出します。台本の都合で作った数字は画面に出しません。

## 確認の道具

- `node dev/sim.js 20`：周回の測定、隠し情報の漏れ、保存からの再開、導入と練習が台本どおりに進むかの確認
- `node dev/modes.js 500`：全カードを同じ方式にしたときの比較
- `node dev/snapshot.js 変更前.html 変更後.html`：同じ乱数で動かして、挙動の一致を確かめる（数値を変えない整理のとき）
