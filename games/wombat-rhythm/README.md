# ウォンバット☆リズムバトン（試作中）

3レーンの切り株をたたく音ゲー。ウォンバット☆シリーズの1作で、舞台はユーカリ村の音楽会。メインは1台の端末をかわりばんこに使う2人対戦で、片方が作った曲を、もう片方がたたいて再現する。

- モード：ふたりで対戦、リズム修行（ストーリー・全10ステージ）、フリープレイ（保存した曲を聴く・挑戦する）、設定（タイミング補正）
- 記録は localStorage の `wbrhythm_` で始まるキーに保存する（`songs` `story` `battlecfg` `offset`）

## 守りたいこと

- 作った本人が試走で70%以上を取らないと出題できない。たたけない曲や、連打だけの曲で勝てないようにするため
- スコアはノーツ数ではなく精度(%)で比べる。空打ちは減点する
- ハンデは「たたく曲の長さ」と「ノーツの消え方」。どちらも、たたく側にかかる
- 3レーンは今のコードの低・中・高の音。どこをたたいても伴奏になじむ
- 判定は画面のノーツで行う（音の遅延の影響を受けにくくするため）。判定の幅と点数は試作用の仮の値
- スマホ・タブレットのタッチ操作向け。同時押しは2つまで

## しくみ

- ウォンバットの絵は [神に愛されたヒメウォンバット](../kami-wombat/) の描画コード（`renderFront` など）を流用し、プレイヤーの色（青・赤）のスカーフを重ねている
- リズム修行の先生（コアラ・カンガルーなど）は [ウォンバット☆どうぶつ陣取り](../wombat-jintori/) の動物のドット絵を流用している
- 音はすべて Web Audio で、その場で鳴らしている（音声ファイルなし）
- 配色はシリーズ共通の「ユーカリ村の昼」。プレイ画面だけ、夕暮れの野外ステージにしている
