# ウォンバット☆どうぶつ陣取り（試作中）

5×5のマス目で、動物コマ5体どうしを戦わせる2人対戦ゲーム。ウォンバット☆シリーズの1作で、舞台はユーカリ村。プレイヤーはウォンバット（青・赤）で、ウォンバット自身はコマにならない。

- モード：ストーリー（全5章・18戦。勝つと「なかま呼びの笛」＝ガチャを1回）、チュートリアル（3レッスン）、2人対戦（全動物／笛で出た動物だけ）、図鑑
- ルールの基本形・ガチャの確率・これまでの検証結果は、ゲーム内の「ルール」に書いてある（そこを正とする）
- メニューの「開発用」から、フリー対戦（AI観戦など）と、AIどうしのシミュレーション（検証）が使える
- 記録は localStorage の `wbjintori_save_v1` に保存する

## 守りたいこと

- フィールド（平原・森林・水辺）の塗り合いが勝負を左右する。適性の倍率の振れ幅は大きくてよい
- ランク5だけの編成は、よく組まれた混成より少し強いくらい。絶対的に強くはしない
- 動物の能力は実際の生態と結びつける。特定の動物だけに刺さるメタ能力は作らない
- コアラとハリモグラは「とくべつな動物」として、ほかにない能力を持つ
- 絶滅動物（いま16種）は強いかわりに毎手番HPが減る（衰え）。衰えで倒れても失点。太古の笛から出る（ストーリーは第3章から）
- 動物は128種（ふつう110・絶滅16・とくべつ2）。能力は今ある仕組みを生態に合わせて割り当てる

- 負けても何も失わない。何度でも挑戦できる
- 図鑑の現実の動物の説明は事実に合わせる。大きさは「めやす」と書く。ゲームの能力は空想をふくむと図鑑に書く

## 見た目

- レガシーRPGの暗い画面とはちがい、ユーカリ村の昼をイメージした明るい配色にしている（ユーカリの霧の地色、ユーカリ緑の主ボタン、ワトルの黄色の差し色）
- タイトルは、平原・森林・水辺のパッチワークの盤にウォンバットを立たせる。ゲームの中心である「フィールドの塗り合い」をそのまま看板にする
- Webフォントは使わず、OS標準の丸ゴシック系で表示する

## ファイル

- `index.html` … ゲーム本体（1ファイル完結。データ・ルール・AI・画面がすべて入っている）
- ドット絵のウォンバットは [ウォンバット☆レガシーRPG 2](../wombat-legacy-rpg-2/) の描画コードを流用
- 動物のドット絵は、リポジトリ共有の [assets/animal-sprites](../../assets/animal-sprites/) のデータを `index.html` に埋め込んで使う（ネットなしで遊べるように）。絵を直したら、`animals.js` の中身を貼り直す
