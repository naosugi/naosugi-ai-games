# ウォンバット☆きんトレ探検隊（試作中）

運動不足のデスクワーカー（中年）向けの、マット（またはタオル）1枚だけでできる約10分の自重トレーニングゲーム。朝か夜に1日1回。ウォンバットはトレーナー役（正面顔が基本）で、運動のお手本は3Dの棒人間。

## しくみ

- メニュー：準備運動 → 8種目（脚・押す・背面・脚のキープ・脚・押す・体幹・プランク）→ 整理運動。種目は日替わり。休けい20秒
- 使う道具はマット1枚だけ。椅子・机・壁を使う種目は入れない（以前あった椅子スクワット・壁腕立て・机腕立て・空気椅子は外した。古い記録の表示のために名前だけ残している）
- 腕立ては、四つんばい腕立て（いちばんやさしい）→ ひざつき腕立て → 腕立て伏せ の順に、強さが上がると出てくる
- 運動中は画面を見られない前提で、音で案内する（低い音＝下げる、高い音＝上げる、回数・残り秒数の読み上げ）。読み上げが使えない環境では「音だけモード」（5回ごとにピピッ等）
- 休けい中に、次の種目のお手本アニメ・注意書き・音のお手本を出す
- お手本は3Dの棒人間。右半身オレンジ・左半身青、ひざ横に「右」「左」。左右交互の種目（バードドッグ・デッドバグ・ニーアップ）は1回ごと、スプリットスクワットは後半で、お手本の左右も入れかわる。指でドラッグすると見る向きを変えられる（ダブルタップで元に戻る）
- 終了後の「楽／ちょうど／きつい」で次回の回数・秒数を自動調整（回数12〜20回、キープ30〜60秒）
- 挑戦クエスト（任意）：1種目を少し増やす。前回「きつい」の日は出さない。成功で経験値＋探検1回
- 経験値 → レベルアップ → スキルを3択で習得・強化 → 探検で動物を確率で発見 → 図鑑
  - 生息地スキル（里・森・草原・水辺・海・寒い土地）＋化石掘り＋観察力
  - 動物のランク（★）＝発見難度。スキルLvが★以上ないと出ない。★は現実の珍しさとは関係ないと明記
  - 朝のトレーニングは昼行性、夜は夜行性の動物が出やすい（区分は確かなものだけ。迷うものは「どちらも」）
  - 3回続けて新種がないと、次は必ず新種（空振り救済）
  - 同じ動物に再会するたび、図鑑の説明（特徴→生息地→食べ物→大きさ）が開く
  - 128種そろうと番外のヒメウォンバットが加わる
- 報酬は1日1回まで（やりすぎ防止）。2回目は記録だけ
- レポート：週刊・月刊・累計。メインは実績（日数・筋トレ時間・回数・キープ秒数・自己ベスト）、消費エネルギーは体重を入れたときだけ幅つきの参考値
- ファクト：条件を満たすと研究・ガイドラインの事実を出典つきで表示。「あなたのリスクが下がった」とは書かず「関連」と書く
- 筋トレ時間は運動ブロックだけを数える（準備・整理運動・休けいは含めない）
- 記録は localStorage の `wbkintore_save_v1`。設定から JSON で書き出し・読み込みできる

## 見た目と操作（スマホ前提）

- 下にタブ（ホーム・図鑑・スキル・レポート・設定）、大事なボタンは画面下に固定。シート型の確認画面
- ウォンバットコーチは正面顔。まばたき、しゃべるときの口の動き、気分（ふつう・うれしい・応援・しょんぼり）で表情と動きが変わる。探検で歩くときだけ横向き
- 吹き出しの文字は1文字ずつ出る（タップで全部）
- スマホの縦画面（375×667 以上）で、ホーム・メニュー・運動中・終了後の画面がスクロールなしで収まる。運動中はお手本の大きさを画面の高さに合わせて変える
- 運動中：残りを示す円のゲージ、下げる（青）・上げる（オレンジ）・キープ（黄）で背景と色が変わる。開始前に3・2・1。操作は下の丸ボタン（やめる・停止・次へ）
- 振動（対応端末のみ。設定でOFF可）：下げる・上げる・カウントダウン・種目の終わり
- 演出：紙吹雪、レベルアップの全画面演出、探検の歩くシーン→「！」→シルエットから正体が現れる、経験値のカウントアップ、スタンプのポン、自己ベスト更新の表示
- 「動きを減らす」設定の端末ではアニメーションを止める

## 守りたいこと

- 罰を作らない（休んでも何も減らない）
- 推測を事実のように見せない。試算は幅と計算式を出す。経済効果や換算のお遊びは入れない
- 健康上の注意（持病・痛みがある人は医師に相談、痛みが出たら中止、息を止めない）を出す
