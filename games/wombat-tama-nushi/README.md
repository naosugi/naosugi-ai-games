# ウォンバット☆多摩防衛隊（試作中）

「ウォンバット☆たま旅すごろく」の素材（多摩30市町村の地図・名物・豆知識・ドット絵・音源の仕組み）を使った、子ども向けの協力ゲーム。

## 狙い・守りたいこと

- 対象は小学校中学年。未就学児も、保護者が作戦を受け持てば一緒に遊べる
- 勝ち負けはない。なかなおりした「ぬし」の数でエンディングが5段階に分かれ、どれも前向きな結末にする
- もやもやは「ぬし」のため息。退治ではなく、名物でもてなして「なかなおり」する
- 参考にした仕組み：パンデミック（隣へ広がる・発生源を断つ）、おばけ屋敷の宝石ハンター（サイコロ移動・こまった町）、レシピ（具体的な献立・「それ、ほしい！」）

## ルールの要点

- むずかしさ：やさしい（ぬし2・4コース）、ふつう（ぬし3・4コース）、むずかしい（ぬし4・全体マップ）
- 手番：サイコロ（1,2,2,3,3,4）の目まで移動 → 1行動（はらう／とどける／なかなおり）
- もやもやが0になった町は、献立の名物と、寝床までの距離の手がかりをくれる
- 手番の終わりに、ぬしが順番にため息（寝床の近くほど出やすい）。数手番ごとに大あくび
- 3つたまった町は「こまった町」。あふれると隣の町1つへ流れる
- 3匹以上は「あいのり」：サイコロの目に関係なく仲間のいる町へ行ける。人数差は `PLAYER_ADJ`（ゆうがたまでの手番・ため息の回数）でならす
- 数値は `MODES`（core 部分）にまとめてある。ボットでの試算のみなので、実際に遊んで調整する

## 作り方

`index.html` は1ファイル完結。地図・ドット絵・名物アイコン・町のデータは wombat-tama-sugoroku からそのまま流用している。
瑞穂町の地図の形は元の作品で空になっていたため、同じ出典（国土数値情報。JapanCityGeoJson の形式）から作り直して補った。
